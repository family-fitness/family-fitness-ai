# AI-5 · `POST /v1/fitness/trajectory`

계약은 `../03` §7. **개인의 미래가 아니라 집단 분포에 대한 진술이다** — 횡단면
자료로 만든 값이라 `predict`·`forecast` 계열 이름을 쓰지 않는다.

---

## 1. 지금 있는 것으로는 안 된다

`age_band_value_quantiles.csv` 는 **연령 구간**당 한 행이다. 계약이 요구하는 것은
**나이 한 살**당 한 행이다 (`../03` §7.2 의 `bands[] = {age, p10, p50, p90, n}`).

| | 지금 산출물 | 계약이 요구하는 것 |
|---|---|---|
| 행의 단위 | `(연령대, 구간, 성별, 항목)` | `(항목, 성별, **나이**)` |
| 예 | 성인 여 19~24세 한 행 | 19·20·21·22·23·24세 여섯 행 |

구간을 그대로 그리면 곡선이 계단이 된다. 24세와 25세 사이에서 뚝 떨어지는 것은
`../02` §5.5 가 점수에서 없애기로 한 바로 그 현상이다.

**그러므로 나이 단위 분위수를 새로 산출한다.** 이것이 이 이슈의 실체다.

---

## 2. 산출물

### `age_value_bands.csv` — 나이 한 살 단위 원값 분위수

| 열 | 내용 |
|---|---|
| `item_code` · `item_name` · `unit` | 측정 항목 |
| `sex` | `M` · `F` |
| `age` · `age_unit` | **한 살(유아기는 한 달)씩.** 구간이 아니다 |
| `age_group` | 그 나이가 속한 연령대 |
| `p10` · `p50` · `p90` | `../03` §7.2 의 밴드 |
| `n` | 그 나이·성별·항목의 표본 수 |

- **분위수는 그 나이의 원자료에서 직접 낸다.** 구간 분위수를 보간해 만들지 않는다 —
  보간하면 없는 사람을 지어내는 것이고, `n` 이 그 사실을 감추게 된다
- **만 7~10세는 행이 없다.** 측정 0건이다 (`../02` §2.2). 빈 값을 채워 넣지 않고
  곡선이 끊긴 채로 나간다
- `n < 30` 인 나이는 행을 남기되 `low_sample` 판단의 재료가 된다 (`../03` §7.2)

### 왜 점수가 아니라 원값인가

`../02` §6 ② 가 미결이고 **확정 전 기본값이 raw 밴드**다. 산출물을 원값으로 두면
점수 축이 확정돼도 그 위에서 점수로 바꿀 수 있다 — 앵커가 산출물에 있기 때문이다.
반대 방향은 안 된다. **되돌릴 수 있는 쪽으로 만든다.**

## 3. 응답

`../03` §7.2 를 그대로 낸다. 주의할 것 셋.

| 필드 | 규칙 |
|---|---|
| `basis` | 고정값 `cross_sectional_group_distribution` |
| `notice` | **곡선과 함께 반드시 노출.** 문구를 고쳐 쓰지 않는다 |
| `child_scope` | **항상 `null`.** 성장 투영 수치를 아이에게 보여주지 않는다 |

`item_code` 기본값은 `028`(상대악력)이다 — 유아기부터 성인까지 시험이 이어지는 세
항목(`012`·`028`·`018`) 중 하나이고, 그중 점수화 대상인 것이 `012`·`028` 둘이다.

**`horizon_years` 는 밴드를 자르는 값이지 예측 구간이 아니다.** 지금 나이부터
`age + horizon_years` 까지의 행을 돌려준다.

**시험이 바뀌는 경계를 한 곡선에 잇지 않는다** (`../02` §5.5). `020` 은 유소년 15m,
청소년·성인 20m다. 원값 축에서는 이것이 서로 다른 척도라 이어 그리면 거짓 추세가
된다 — 경계에서 곡선을 끊고, 끊긴 이유를 응답에 남긴다.

---

### 3.1 백엔드는 이것을 `predictions` 라 부른다

`prediction_points` 는 `p10`·`p50`·`p90` · `years_from_now` 로 **우리 `bands[]` 와
모양이 그대로 맞는다.** 어긋나는 것은 이름과 주장이다
([AI-13](AI-13-backend-contract-reconciliation.md) §3.7).

| | 우리 (`../03` §7) | 백엔드 |
|---|---|---|
| 이름 | `trajectory` · `bands` | `predictions` · `prediction_points` |
| 주장 | 집단 분포 (`cross_sectional_group_distribution`) | "미래 체력 변화 예측" |
| 시나리오 | 없다 | `scenario` (MAINTAIN · IMPROVE) |

`../03` §7 은 **`predict`·`forecast` 계열 이름을 두지 않는다**고 명시적으로
금지했다. 횡단면 자료라 개인의 미래를 다루지 않기 때문이다.

**`scenario` 는 우리가 낼 수 없다.** "개선 시나리오"를 내려면 개인의 변화율을
가정해야 하고, 횡단면 자료에 그 근거가 없다. `MAINTAIN` 하나만 채우거나
시나리오 축을 빼기를 제안한다.

이름은 저장 쪽 사정이라 우리가 정하지 않는다. **다만 화면 문구가 "예측"이 되면
`notice`(§3)와 모순된다** — 그것은 알려야 한다.

## 4. 검사

| 무엇 | 왜 |
|---|---|
| `child_scope` 가 항상 `null` | `../03` §7.2 |
| 만 7~10세 구간에 밴드가 없다 | 측정 0건을 메우지 않는다 |
| 응답 필드에 `predict`·`forecast` 가 없다 | `../03` §7 |
| 측정값이 비어도 `200` | 밴드만 나가고 개인 위치가 없다 |
| `020` 이 연령대 경계에서 끊긴다 | 척도가 다르다 |
