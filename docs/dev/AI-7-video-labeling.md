# AI-7 · 운동영상 수집과 라벨링

공단 운동영상에 **연령대·체력요인·운동명·시작 지점**을 붙인다. 데이터 제약은
`../02` §2.3·§3.2, 청크 규약은 `../04` §1.

**이 이슈는 라벨이 얼마나 붙는지를 먼저 재는 일이다.** 붙지 않는 것이 정상 결과일 수
있고, 그때 `video: null` 이 결함이 아니라는 계약(`../03` §5.7)이 그 사실 위에 서 있다.

---

## 1. 알고 시작하는 것

공단 채널 전수 362편 / 재생목록 15종을 이미 수집해 본 결과다 (`../02` §2.3).

| | 편수 |
|---|---|
| 유아기 | 31 |
| 청소년 | 12 |
| 성인 | 5 |
| **연령 추정 불가** | **314 (87%)** |

- **유소년 전용 영상은 0편이다.** 「연령별 맞춤 운동」이 영유아·청소년·청년·중장년으로
  나뉘고 유소년 구간이 없다
- 설명문 228편(63%)이 체력요인을 언급하지 않는다. 25편은 요인 6~7개를 나열한 상용구다
- **설명문만으로 요인을 정할 수 있는 영상은 30% 수준이다**

그래서 이 이슈의 성공 기준은 "전부 라벨링한다"가 아니다. **얼마나 붙었고 어디가
비는지를 수치로 남기는 것**이다.

## 2. 수집

```bash
python -m family_fitness_ai.labeling.collect        # 메타데이터
python -m family_fitness_ai.labeling.label          # LLM 라벨링
```

`../02` §3.2 의 제약을 코드가 지킨다.

| 규칙 | 왜 |
|---|---|
| `channels.list` → `playlists.list` → `playlistItems.list` → `videos.list` | **`search.list` 는 일일 100회 제한**이다 |
| 응답을 JSONL로 캐시한다 | 재실행이 API를 다시 때리지 않는다 (`../02` §4) |
| 프레임 추출은 한 모듈에서만 | 시트 생성 후 원본을 지운다 |
| 영상·프레임·썸네일을 재배포하지 않는다 | `../02` §3.2 |

**`raw/frames/` 는 30일 후 삭제된다** (`../01` §4.3). 재배포 금지 원칙을 운영으로
옮긴 것이라, 로컬에서도 같은 수명을 지킨다.

D3(국민체력100 동영상 정보 API)와 D4(유튜브 채널)를 **같은 인터페이스로 다룬다** —
`../02` §1.1 이 수집 계층에 요구한 것과 같은 이유다.

## 3. 라벨링

LLM으로 한다 (`../01` §3.3 의 `labeler:<model>/<prompt-v>`).

| 라벨 | 값 | 없으면 |
|---|---|---|
| `age_group` | `AgeGroup` | **`null`. 추정하지 않는다** |
| `fitness_factor` | `FitnessFactor` 0~3개 | 빈 값 |
| `exercise_names` | [AI-6](AI-6-prescription-corpus.md) 의 어휘 638개 **중에서만** | 빈 값 |
| `start_sec` | 해당 동작 시작 지점 (`../03` §4.2) | `null` |

### 3.1 추정하지 않는 것이 규칙이다

**연령 미상 영상은 아이 프로필에 내보내지 않는다** (`../02` §2.3). 그러므로 라벨러가
"아마 아이용일 것"으로 채우면 그 안전장치가 무력해진다.

| 판단 | 처리 |
|---|---|
| 제목·재생목록에 연령이 명시됨 | 그 값 |
| 설명문에서 추론됨 | **`null`** |
| 판단 불가 | `null` |

**근거 원문을 같은 행에 남긴다** (`../02` §4). 어느 문장을 보고 `유아기` 라고 했는지가
없으면 라벨을 검수할 수 없다.

### 3.2 어휘 밖 운동명을 만들지 않는다

`exercise_names` 는 [AI-6](AI-6-prescription-corpus.md) 의 638개 안에서만 고른다.
계약(`../03` §5.7)이 `sessions[].exercise_name` 을 그 어휘로 제한하므로, 영상 라벨이
어휘 밖 값을 가지면 미션 편성에서 쓸 수 없는 라벨이 된다.

**그래서 [AI-6](AI-6-prescription-corpus.md) 이 먼저다.**

---

### 3.3 백엔드 스키마가 라벨을 강요한다

`exercise_videos` 는 `age_from`·`age_to`·`intensity`·`space`·`noise` 를 전부
`not null` 로 둔다 ([AI-13](AI-13-backend-contract-reconciliation.md) §3.6).

**362편 중 314편(87%)이 연령 추정 불가다** (§1). `not null` 이면 그 314편은 넣을 수
없거나 **지어낸 값을 넣어야 한다.**

- `AGENTS.md` §4 — "데이터가 없을 때 더미로 채워 '돌아가게' 만들지 않는다"
- 지어낸 연령은 §3.1 이 막으려던 바로 그 사고다 — 아이에게 성인 영상

**→ nullable로 바꾸기를 요청한다.** `null` 은 "라벨 없음"이고, 라벨 없는 영상은
아이 프로필에 나가지 않는다 (`../02` §2.3).

**그리고 우리는 `exercise_videos` 에 직접 쓰지 않는다.** 그 테이블은 Spring Boot
소유이고 우리 DB 역할은 `ai_documents` 하나로 제한된다 (ADR-001). 라벨은 CSV로
내고 백엔드가 적재한다 — `../01` §4.2 의 "`ai_*` 컬럼에 쓴다"는 낡았다.

`space`·`noise`·`equipment` 는 우리가 라벨해야 하는 새 축이다. `../03` §4.1 은
"라벨이 그 필드를 갖지 않는다"를 전제로 필터를 거절했는데, 스키마가 그 필드를 갖는다
([AI-9](AI-9-videos-search.md) §1). **설명문에서 층간소음을 판정할 수 있는지는
재 봐야 한다** — 요인조차 63%가 언급되지 않는 설명문이다.

## 4. 산출물

### `data/interim/video_labels.csv`

| 열 | 내용 |
|---|---|
| `video_id` · `title` · `playlist` · `duration_sec` | 수집 메타 |
| `age_group` · `fitness_factors` · `exercise_names` · `start_sec` | 라벨 |
| `space` · `noise` · `equipment` · `intensity` | 백엔드 스키마가 요구하는 축 (§3.3) |
| `evidence_text` | 그 판단의 근거가 된 원문 |
| `labeler_version` | `labeler:<model>/<prompt-v>` (`../01` §3.3) |

**커밋하지 않는다.** 공개 산출물은 라벨 메타데이터로 한정하고(`../02` §3),
`exports/` 로 나간다 (`../01` §4.3).

### 라벨 공백 리포트 — 이 이슈의 본 산출

| 재는 것 | 왜 |
|---|---|
| 연령대별 라벨된 편수 | `../02` §2.3 의 31/12/5/314 가 라벨링 뒤 어떻게 바뀌는가 |
| 요인별 편수 | 요인 하나에 영상이 0편이면 그 요인의 미션은 항상 `video: null` |
| **유소년 편수** | 0편일 것으로 예상된다. 0이면 0이라고 보고한다 |
| 어휘 매칭률 | 638 중 몇 개에 영상이 붙었는가 |
| `start_sec` 이 붙은 비율 | 안 붙으면 영상 처음부터 재생된다 |

**데이터가 없을 때 더미로 채워 "돌아가게" 만들지 않는다** (`AGENTS.md` §4).
유소년 영상이 0편이면 유소년 미션은 `video: null` 로 나가고, 그것이 계약이 이미
허용한 상태다 (`../03` §5.7).

---

## 5. 초등 페르소나가 두 번 빈다

`../02` §2.2 의 측정 공백(만 7~10세 0건)과 §2.3 의 영상 공백(유소년 0편)이 겹친다.
**초등 페르소나는 측정도 영상도 비는 구간이다.**

이 사실을 이 이슈에서 감추지 않는다. 계약은 두 공백을 모두 정상 응답으로 정의해
두었다 — `factors: []` (`../03` §2.4) 와 `video: null` (`../03` §5.7). 서비스가
그 구간에서 무엇을 보여줄지는 화면의 결정이고, 그 판단의 재료가 §4 리포트다.
