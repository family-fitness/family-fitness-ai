# AI-1 · 연령 구간별 점수 분포

측정 원자료를 요인 점수(0~100)로 바꾸고, 기준표가 정의한 연령 구간마다 분포를 낸다.
그래프는 이 산출물을 그린다.

**연령 구간을 기준표에 맞추는 이유** — 구간마다 등급 문턱이 다르고, 점수는 그 문턱을
공통 눈금에 고정해서 나온다. 임의로 5세씩 끊으면 한 구간 안에 서로 다른 문턱이 섞여
점수의 뜻이 흐려진다.

점수 규약의 정본은 `../02-공공데이터-관리-규약.md` §5다. 여기서는 그 규약을 어떻게
돌리고 무엇이 나오는지만 적는다.

---

## 1. 실행

원자료 zip에는 측정 기록과 컬럼정의서만 들어 있다. **등급 기준표는 레포에 있으므로
따로 챙기지 않는다.**

```bash
unzip kspo-measure-202407-202607.zip -d ~/받은자료/kspo-measure
make distribution DATA_DIR=~/받은자료/kspo-measure   # 저장소 루트에서
```

**기간별로 나뉜 CSV를 한 디렉터리에 모아 두면 된다.** 파일명 순으로 읽어 이어 붙이므로
개수와 기간은 자유다. 하위 디렉터리는 뒤지지 않으니, zip이 폴더 하나를 만들며 풀렸다면
그 폴더를 가리킨다.

기준표 원본이 갱신됐을 때만 xlsx를 준다. 문턱 CSV가 함께 다시 만들어진다.

```bash
python -m family_fitness_ai.stats.distribution \
    --data-dir ~/받은자료/kspo-measure \
    --criteria ~/받은자료/등급평가항목및기준.xlsx
```

`--out` 기본값은 `data/release/` 다. 저장소 루트가 아닌 곳에서 돌리면 기준표를 찾지
못하고 멈춘다.

---

## 2. 산출물

`data/release/` 에 셋이 나오고 전부 커밋한다. 인코딩은 `utf-8-sig` — 엑셀로 연다.

### `age_band_score_distribution.csv` — 그래프용 도수표

한 행이 하나의 점수 구간이다. `(연령대, 연령구간, 성별, 항목)` 마다 10개 행이 있다.

| 열 | 내용 |
|---|---|
| `age_group` · `age_lo` · `age_hi` · `age_unit` | 연령 구간. 유아기만 `개월` |
| `sex` | `M` · `F` |
| `factor` · `item_code` · `item_name` | 요인과 측정 항목 |
| `bin_lo` · `bin_hi` | 점수 구간 (0~10 … 90~100) |
| `count` · `ratio` | 그 구간의 인원과 비율. `ratio` 합은 1 |

### `age_band_score_summary.csv` — 칸별 눈금과 분위수

한 행이 하나의 `(연령대, 연령구간, 성별, 항목)` 칸이다. **문제가 있으면 `status` 를
먼저 본다.**

| 열 | 내용 |
|---|---|
| `status` | `ok` 또는 눈금을 못 만든 사유 (§4) |
| `n_measured` · `n` | 측정값이 있는 인원 · 점수가 나온 인원 |
| `method` | `ecdf`(기본) 또는 `linear`(`n < 30` 폴백) |
| `grade3_from_p25` | 3등급 문턱이 없어 40점 앵커를 `p25` 로 채웠는가 |
| `anchor_0` … `anchor_100` | 그 칸의 점수 눈금. 40·60·80은 기준표, 0·100은 분포 `p2`·`p98` |
| `value_min` · `value_max` | 원 측정값의 범위. 이상치를 눈으로 잡는 용도다 |
| `score_p10` … `score_p90` · `score_mean` | 점수 분포 |

### `grade_thresholds.csv` — 기준표를 편 것

등급 기준표(xlsx)를 한 행 = 한 문턱으로 편 표다. 원본 없이 문턱을 확인할 수 있고,
산출도 이 파일을 기본으로 읽는다.

## 4. 산출되지 않은 칸 33개

전부 **등급 문턱이 겹치거나 뒤집혀 눈금이 서지 않는** 경우다
(`status = anchors_not_monotonic`). 데이터가 없어서가 아니라 기준이 그렇게 생겼다.

| 연령대 | 항목 | 칸 | 원인 |
|---|---|---|---|
| 성인 | `021` 10m 4회 왕복달리기 | 14 | 3등급 문턱이 없어 `p25` 로 채웠는데 그 값이 2등급 문턱을 넘는다 |
| 성인 | `022` 제자리멀리뛰기 | 8 | 위와 같다 |
| 청소년 | `017` 눈-손 협응력 | 5 | 위와 같다 |
| 유아기 | `009` 윗몸말아올리기 | 5 | 2·3등급 문턱이 둘 다 0회다. 40점과 60점을 가를 값이 없다 |
| 유소년 | `043` 반복옆뛰기 | 1 | `p25` 가 2등급 문턱과 같다 |

가장 큰 덩어리를 예로 들면, 성인 여 25~29세 제자리멀리뛰기는 `p25` 가 145cm인데
2등급 문턱이 144cm다 — 그 구간 여성의 75% 이상이 이미 2등급 문턱을 넘는다.

**처리 방식이 규약에 없어 점수를 내지 않는다.** 미결로 잡혀 있다
(`../02-공공데이터-관리-규약.md` §6 ⑨). 정해지면 여기 산출도 함께 바뀐다.

## 5. 범위 밖

- **어르신** — 기준항목이 미정이라 점수를 내지 않는다 (`../02` §6 ⑦). 다만 기준표에
  노년기 시트는 실재하므로 열 매핑만 정하면 풀 수 있다
- **`044` 눈-손 협응력(유소년)** — 기준단위 `회` 와 데이터단위 `초` 가 어긋난다
  (`../02` §6 ①)
- **신체조성(`003`·`004`·`018`·`042`)** — 기준이 구간 형태라 0~100 척도가 성립하지
  않는다 (`../02` §5.4)
- **그래프 이미지** — 만들지 않는다. 도수표가 그래프의 데이터고, 그리는 쪽은 화면이다
