# AI-10 · `POST /v1/coach/messages`

계약은 `../03` §6, 거부 규약은 `../04` §4.

**이 갈래의 본체는 답하는 것이 아니라 답하지 않는 것이다.** 검색·생성은
[AI-8](AI-8-vector-index.md) 이 이미 하고, 여기서 새로 만드는 것은 거부 판정과
인용 검증이다.

---

## 1. 순서

```
질문
 │
 ├─ 의료 질의인가 ────── 예 ─→ 거부 medical_query   (검색조차 하지 않는다)
 │
 ├─ 검색 (연령 필터 · 임계값이 WHERE 절에)
 │   ├─ 임계 통과 0건 ─→ 거부 no_relevant_source
 │   └─ 연령 필터 후 0건 ─→ 거부 age_filter_empty
 │
 ├─ LLM 생성 (컨텍스트 최대 5청크)
 │
 └─ 검증 ─ 인용 0개거나 [n] 이 범위 밖 ─→ 거부 no_citation_generated
```

**`../04` §4.1 의 셋은 LLM을 호출하지 않는다.** 없는 근거로 답을 만들 기회를 주지
않는 것이 프롬프트로 당부하는 것보다 확실하다.

**우회 경로를 두지 않는다** (`../04` §4.2). 모든 응답이 §1 의 검증을 통과한다.

---

## 2. 거부는 오류가 아니다

| | |
|---|---|
| HTTP | `200` (`../03` §2.2) |
| 재시도 | **하지 않는다** |
| 예외 | 던지지 않는다 — 던지면 거부가 오류 로그에 섞여 거부율을 못 잰다 |
| 저장 | API 서버가 저장한다. **거부율이 품질 지표다** (`../03` §8) |
| 문구 | `../04` §4.3 의 두 문구. 고쳐 쓰지 않는다 |

> ⚠ **`coach_messages` 에 `refused`·`refusal_reason` 컬럼이 없다**
> ([AI-13](AI-13-backend-contract-reconciliation.md) §3.2). 거부 응답을 저장할 자리가
> 없으면 `../01` §5 의 거부율 지표가 나오지 않는다. 우리는 계약대로 내되, 저장
> 컬럼은 합의 항목이다.

### 2.1 백엔드와 맞춰야 할 것

| 항목 | 우리 (`../03` §6) | 백엔드 |
|---|---|---|
| 경로 | `POST /v1/coach/messages` | 클라이언트용 `POST /api/v1/coach/chat` |
| 인용 식별자 | `citation.chunk_id` 문자열 | `coach_message_citations.ai_document_id` uuid |
| 대화 문맥 | 없다 — 단발 질의응답 | `coach_messages.conversation_id` 가 있다 |

경로는 층이 달라 겹치지 않는다. **인용 식별자는 겹친다** —
[AI-8](AI-8-vector-index.md) §2.2 가 풀려야 정해진다.

**대화 문맥을 받을지는 정해지지 않았다.** 받으면 `../03` §6.1 에 필드가 늘고,
`../04` §4 의 거부 판정이 무엇을 근거로 하는지가 바뀐다 (앞 질문이 의료 질의였다면?).
기본값은 받지 않는 것이다.

---

## 3. 의료 질의 판정

부상·통증·질환·약물 (`../04` §4.1). **검색 전에 판정한다.**

**어휘 목록으로 시작한다.** 목록은 놓치는 것이 있지만, 놓친 것은 뒤의 인용 검증에
걸려 근거 없는 답이 되지는 않는다. 반대로 LLM 판정으로 하면 판정 자체에 LLM 호출이
하나 더 붙고, `../01` §3.1 이 "LLM 호출은 한 곳뿐"으로 묶은 이유와 어긋난다.

**놓친 사례를 모아 목록을 넓힌다.** 목록과 그 근거를 한 모듈에 둔다.

---

## 4. 인용 검증

| 검사 | 실패하면 |
|---|---|
| `citations` 가 1개 이상 | `no_citation_generated` |
| 본문 `[n]` 이 전부 `citations` 범위 안 | 같다 |
| `citations[].chunk_id` 가 실제 검색된 청크의 것 | 같다 |

**`answer` 를 편집해서 통과시키지 않는다.** `[3]` 이 범위 밖이면 그 번호를 지우는
것이 아니라 응답 전체를 거부로 바꾼다 — 지우면 어느 문장이 근거를 잃었는지 모른 채
나간다.

**인용률은 임계가 아니라 절대값 100%다** (`../01` §5).

---

## 5. 검사

| 무엇 |
|---|
| 의료 어휘 질의에서 검색 함수가 **호출되지 않는다** |
| 검색 0건이면 LLM 함수가 **호출되지 않는다** |
| LLM이 인용 없는 답을 내면 `refused: true` · `200` |
| 본문 `[n]` 이 범위를 벗어나면 거부 |
| 거부 응답이 예외를 던지지 않는다 |
| 아이 연령대 질의의 인용에 성인 청크가 0건 |
