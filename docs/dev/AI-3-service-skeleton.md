# AI-3 · 서비스 골격

FastAPI 앱이 서고, 설정을 읽고, 오류를 한 모양으로 내고, 요청 한 건이 로그 한 줄이
되는 데까지. **엔드포인트는 넣지 않는다** — 그것은 AI-4 부터다.

계약은 `../03` §2, 런타임은 `../01` §2.3·§3.2·§5.

---

## 1. 왜 먼저 하나

엔드포인트 넷이 같은 것을 필요로 한다 — 오류 봉투, 설정, 준비성 판단, 로그 한 줄.
엔드포인트마다 만들면 네 벌이 되고, 네 벌은 갈라진다. `../03` §2.2 의 오류 형태가
엔드포인트마다 다르면 계약이 아니다.

**그리고 이것은 외부 결정을 하나도 기다리지 않는다.** 임베딩 모델이 정해지기 전에
할 수 있는 일이다.

---

## 2. 넣는 것

### 2.1 앱과 경로

| 경로 | 내용 |
|---|---|
| `GET /healthz` | 프로세스가 살아 있다. 의존을 확인하지 않는다 |
| `GET /readyz` | 기준표·산출물·벡터 연결·`SIM_THRESHOLD` 를 확인한다 |
| `/v1/*` | AI-4 부터 붙는다 |

**`/readyz` 는 `/healthz` 와 다르다** (`../01` §2.3). 산출물을 못 읽는 채로 요청을
받으면 빈 결과가 나가고, 그것이 "AI가 답을 못 한다"로 기록된다.

`/readyz` 가 확인할 것과 실패했을 때의 표시를 함께 돌려준다. 준비되지 않은 이유가
`503` 하나로 뭉개지면 배포 중에 무엇이 안 됐는지 알 수 없다.

```json
{"ready": false, "checks": {"release": true, "criteria": true,
                            "vector": false, "sim_threshold": false}}
```

**`SIM_THRESHOLD` 가 비어 있으면 준비되지 않은 것이다** (`../04` §6 ②). 값이 없는
채로 검색하면 임계 없는 검색이 되어 무관한 청크가 근거로 실린다.

### 2.2 설정 — `common/settings.py`

`../01` §3.2 의 환경변수를 타입 있는 객체 하나로 읽는다.

- **기동 시 한 번 읽고 검증한다.** 요청마다 `os.environ` 을 보지 않는다
- 없어도 되는 값과 없으면 안 되는 값을 나눈다. `SIM_THRESHOLD` 는 후자다
- **기본값을 코드에 박지 않는다.** `VECTOR_BACKEND` 만 예외로 `faiss` 다 — DB가
  서기 전에도 개발이 멈추지 않게 하려는 것이고, 그 이유가 `../01` §1 에 있다
- 값을 로그에 찍지 않는다. 이름과 "설정됨/비어 있음"만 남긴다

### 2.3 오류 — `../03` §2.2 하나의 모양

```json
{"error": {"code": "BAD_REQUEST", "message": "..."}}
```

- 예외 하나가 이 봉투 하나로 변환된다. 라우터마다 `try` 를 쓰지 않는다
- **`refused: true` 는 이 경로를 타지 않는다.** 거부는 `200` 이고 오류가 아니다
  (`../03` §2.2). 예외로 만들면 거부율을 측정할 수 없다
- `ITEM_NOT_ALLOWED` — 측정 항목 `005`·`006` 이 오면 `400` (`../03` §9).
  **검증이 요청 모델에 있어야 한다.** 라우터 안에서 검사하면 엔드포인트마다 빠뜨린다

### 2.4 공통 타입 — `common/types.py`

`../03` §2.4 의 타입을 한 곳에 둔다. `AgeGroup`·`Sex`·`InputLevel`·`Band`·
`FitnessFactor`·`Role`. **문자열 리터럴을 라우터에 흩지 않는다** — `../02` §2.1 이
`유아기` 만 '기'가 붙는다고 경고한 그 값들이다.

`stats/items.py` 의 `SCORED_AGE_GROUPS` 와 겹친다. **정본은 `common/types.py` 로
옮기고 `stats` 가 가져다 쓴다** — 계약의 값이지 통계의 값이 아니다.

### 2.5 로그 — `../01` §5

요청 한 건이 구조화 로그 한 줄이다.

| 남긴다 | 남기지 않는다 |
|---|---|
| 경로 · 지연 · 상태 · `profile_ref` | **측정값 원본 · 질문 원문** |
| 거부 여부와 사유 · 강등 여부 | 이름·생년월일·연락처 |
| 인용 수 · 연령 필터 제외 수 | 환경변수 값 |

`profile_ref` 는 불투명 참조라 로그만으로 사람을 특정할 수 없다 (`../03` §2.4).

## 3. 실행

```bash
uvicorn family_fitness_ai.api.app:app --reload --port 8000
curl localhost:8000/readyz
```

## 4. 의존성

`pyproject.toml` 에 더한다. `../01` §1 이 확정한 것만 넣는다.

| 패키지 | 왜 |
|---|---|
| `fastapi` · `uvicorn` | `../01` §1 |
| `pydantic-settings` | §2.2 의 설정 검증 |

**LangGraph·pgvector·LLM SDK는 여기서 넣지 않는다.** 쓰는 이슈에서 넣는다 —
지금 넣으면 CI가 쓰지 않는 것을 설치하고 그 버전을 관리해야 한다.

## 5. 하지 않는 것

| 뺀 것 | 넣어야 하는 시점 |
|---|---|
| 인증 헤더 | 퍼블릭 노출 때. **노출보다 먼저** (`../03` §12) |
| `X-Request-Id` | 장애 추적이 실제로 안 될 때 |
| `meta` 봉투 (`latency_ms`·`model_version`) | 운영 대시보드를 만들 때 |
| 레이트 리밋 | 내부망 전용이라 호출자가 하나다 |

`../03` §12 의 목록과 같다. 골격이라고 해서 "나중에 쓸 것"을 미리 넣지 않는다.
