# 02 · 공공데이터 관리 규약

국민체력100 공공데이터를 **어디서 받아, 어디까지 쓰고, 무엇으로 바꾸는가**를 확정한다.
API 응답에 실리는 값의 뜻은 여기서 정해진다.

앱 화면에 보이는 인용 문자열은 형식이 따로 있다 (`04` §1).

### 1.1 파일데이터가 주 소스다

월별 CSV가 API 응답의 **상위집합**이다. API 23개 필드 중 21개가 그대로 있고, 빠진
둘(`row_num`·`age_class`)은 조회 순번과 파생값이라 손실이 아니다. 파일에만 있는
컬럼이 5개 더 있다.

| | API | **파일데이터** |
|---|---|---|
| 트래픽 한도 | 1,000회/일 | **없음** |
| 회원 식별자 | 없음 | `MBER_SEQ_NO_VALUE` 있음 |
| 이상치 비율 | ~1% | **0.01~0.02%** |
| 유소년 비중 | 6.8% | **17.1%** (2.5배) |

**API 호출은 스펙 검증용으로만 쓴다.** 수집 계층은 API와 CSV를 같은 인터페이스로
다뤄, 소스를 바꿔 끼워도 코드가 바뀌지 않게 한다.

### 1.2 수집 범위 — 최근 24개월

전량(2011~, 약 294만 건) 수집은 가능하지만 더 낫지 않다. **오래된 데이터는 표본을
늘리는 대신 기준선을 과거로 끌어당긴다.** 사용자에게 보여줄 값은 "지금 또래 대비"다.

2개월(70,200건)만으로도 유소년~성인 전 셀이 n ≥ 100이다. 24개월이면 셀당 중앙값 약
3,400이 된다.

- 최근 24개월을 기준선으로 삼는다. 현재 확보분은 2024-07 ~ 2026-07(25개월)이다
- 더 과거 파일은 연도 효과 확인용 표본으로만 쓴다
- **기준 기간을 화면·리포트에 명시한다** (예: "2024.07~2026.07 측정자 기준")

## 2. 데이터의 모양 — 확인된 사실

### 2.1 연령 구분 값은 다섯 개이고 표기가 비대칭이다

**API 전수 2,937,487건 기준**이다. 다섯 값의 건수 합이 전체와 정확히 일치하므로
이것이 값의 전체 집합이다. (파일데이터 24개월분의 연령대 구성비는 다르다 — §1.1)

| 값 | 건수 | 비중 | 공식 연령 |
|---|---|---|---|
| `성인` | 1,311,744 | 44.7% | 만 19~64 |
| `청소년` | 984,336 | 33.5% | 만 13~18 |
| `어르신` | 401,730 | 13.7% | 만 65~ |
| `유소년` | 199,090 | 6.8% | 만 11~12 |
| `유아기` | 40,587 | 1.4% | 만 4~6 (48~83개월) |

> ⚠ **`유아기` 만 '기'가 붙는다.** `유아`·`유소년기`·`청소년기`·`성인기`·`어르신기` 는
> 전부 0건이다. 패턴으로 추론하지 말고 다섯 문자열을 상수로 고정한다.

```python
AGE_GBN = ("유아기", "유소년", "청소년", "성인", "어르신")  # 실측 확정. 변형 금지
```

### 2.2 만 7~10세는 측정 데이터가 0건이다

25개월 전수 670,539행을 연령별로 집계한 결과, **만 7·8·9·10세의 측정 건수는 0**이다.
분포는 만 4~6세(25,333건) → **공백 4년** → 만 11~12세(81,845건)로 이어진다.

**공백은 실재한다.** 초등 저·중학년 구간은 이 데이터로 백분위를 낼 수 없고, API는 그
구간에서 점수를 `null` 로 돌려준다. 오류가 아니다.

이 구간이 어느 `age_group` 값을 쓰는지는 정해지지 않았다 (§6 ⑤). 공식 구간은
유아기(만 4~6)에서 유소년(만 11~12)으로 건너뛴다.

### 2.3 유소년 전용 운동영상은 0편이다

공단 채널 전수 362편 / 재생목록 15종을 수집한 결과다.

| 구분 | 편수 |
|---|---|
| 유아기 | 31 |
| 청소년 | 12 |
| 성인 | 5 |
| **연령 추정 불가** | **314** |

「연령별 맞춤 운동」 시리즈는 영유아·청소년·청년·중장년으로 나뉘고 **유소년 구간이
없다.** §2.2의 측정 공백과 겹쳐 초등 페르소나는 영상과 측정이 모두 비는 구간이 된다.

설명문 길이는 중앙값 305자이나 **228편(63%)이 체력요인을 언급하지 않고**, 25편은
요인 6~7개를 나열한 상용구다. 설명문만으로 요인을 정할 수 있는 영상은 30% 수준이다.

**따라서 연령 미상 영상은 아이 프로필(`유아기`·`유소년`·`청소년`)에 내보내지 않는다.**
성인·어르신에는 내보낸다 — 아이에게 성인 영상이 가는 것과 그 반대는 위험이 다르다.

### 2.4 연령 단위 — 유아기만 개월

`MESURE_AGE_CO` 는 유아기만 개월(48~83)이고 나머지는 세다. 월령 원값도 남긴다 —
등급 기준표가 유아기를 개월 구간으로 나눈다.

> ⚠ **세로 환산할 때 반올림이 아니라 내림이다.** 반올림하면 83개월(만 6세)이 만
> 7세가 되어 §2.2의 공백을 거짓으로 메운다.

### 2.5 정제 규칙

API 응답 표본 301행에서 물리적으로 불가능한 값이 3건 나왔다. 이 표본은 성인·사업
초기(2011~2012년) 데이터에 치우쳐 있어 비율을 전체로 외삽할 수 없다 — 파일데이터의
이상치 비율은 훨씬 낮다 (§1.1). **다만 값이 존재한다는 사실은 확인됐고, 정제 없이
넣으면 꼬리 분위수가 오염된다.**

| 항목 | 관측 이상치 | 허용 범위 (제안) |
|---|---|---|
| 체지방률 | 234.0% | 3~60% |
| 허리둘레 | 1.0cm | 40~150cm |
| 수축기혈압 | 40mmHg | 70~200mmHg |

> **허용 범위는 확정값이 아니다.** 관측된 이상치에서 거꾸로 잡은 제안값이고, 전수에
> 적용했을 때 무엇이 얼마나 걸러지는지는 아직 재지 않았다 (§6 ⑦).

## 3. 취급 원칙

- **원자료는 커밋하지 않는다.** 재현은 커밋된 수집·산출 스크립트로 한다
- 공공데이터는 비식별이다. **재식별을 시도하는 코드를 작성하지 않는다**
- 공개 산출물은 **라벨 메타데이터로 한정**한다. 영상·프레임·썸네일은 재배포하지 않는다
- 혈압(`005`·`006`)은 수집물에 있어도 **AI 경계 밖**이다. API로 전송받지 않는다
- 체지방률·허리둘레는 내부 보정용이며 **응답에 수치로 나가지 않는다**

### 3.1 YouTube API 사용 제약

- 허용: `playlistItems.list` · `videos.list` · `playlists.list` · `channels.list`
- 라벨링 목적의 프레임 추출은 한 모듈에서만 하고, 시트 생성 후 원본을 지운다
- 금지: 영상·프레임·썸네일 재배포, 자막 추출, 원본 재가공 배포
- ⚠ **`search.list` 는 일일 100회 제한**이다. `channels.list` → `playlists.list`
  경로를 쓴다

## 4. 산출물 형태 — CSV

DB가 서기 전까지 각 단계 결과를 **사람이 열어볼 수 있는 형태로** 보관한다.

| 용도 | 형태 | 이유 |
|---|---|---|
| **단계별 산출물** | **CSV** | 엑셀로 바로 열린다. 눈으로 검수하고 손으로 고칠 수 있다 |
| 호출 캐시·격리 | JSONL | 중첩이 필요하고 append-only다 |
| 대용량 중간 프레임 | parquet | 열 지향 압축이 유리할 때만 |
| 공개 데이터셋 | JSONL | 스키마가 중첩이고 배포 관례가 그렇다 |

1. **한 단계 = 한 CSV.** 다음 단계가 파일로 받는다. 메모리로 넘기지 않는다
2. **CSV는 평평하게 쓴다.** 중첩이 필요하면 그 단계의 출력 설계가 틀린 것이다.
   다중값은 세미콜론 구분 한 칸으로 둔다
3. **인코딩은 `utf-8-sig`.** 검수하는 사람이 엑셀로 연다
4. **원본 문자열을 버리지 않는다.** 판정 결과와 판정 근거 원문을 같은 행에 남긴다
5. 중간 산출물 디렉터리는 커밋하지 않는다

> **DB로 옮길 때** — 이 CSV들이 그대로 테이블이 되도록 열을 설계한다.

## 5. 체력 점수 정규화 — 요인 단위 공통 척도

측정값을 **요인(근력·유연성·심폐지구력…) 단위 0~100 점수**로 바꾸는 규약이다.
`assessment` 응답의 `score` 가 이 값이다.

### 5.1 문제 — raw 값은 연령대를 넘어 이어지지 않는다

요인은 전 연령대 공통이지만 **그 요인을 재는 시험이 연령대마다 다르다.**

| 요인 | 유아기 | 유소년 | 청소년 | 성인 |
|---|---|---|---|---|
| 근력 | `028` 상대악력 | `028` | `028` | `028` |
| 근지구력 | `009` 윗몸말아올리기 | `009` | `009`·`010` | **`019` 교차윗몸일으키기** |
| 유연성 | `012` 앉아윗몸앞으로굽히기 | `012` | `012` | `012` |
| 심폐지구력 | `020` | `020` | `020`·`035`·`037` | `020`·`035`·`037` |
| 순발력 | `022` 제자리멀리뛰기 | `022` | **`014` 체공시간** | `022`·`041` |
| 민첩성 | **`050`** | **`043`** | **`013`** | **`021`**·`040` |
| 협응력 | **`051`** | **`044`** | **`017`** | — |

전 연령대 공통 항목은 `012`·`028`·`018` 셋뿐이다.

> ⚠ **같은 항목코드가 같은 시험을 뜻하지 않는다.** `020` 은 유소년이 **15m**,
> 청소년·성인이 **20m** 왕복 오래달리기다. 코드가 같아 조인은 되지만 값의 뜻이 다르다.

> ⚠ **이름이 비슷하다고 이어 붙이지 않는다.** 위 표에서 민첩성 행의 `050`(유아 5m 4회
> 왕복)과 `021`(성인 10M 4회 왕복)은 거리가 달라 별개 항목이다. 한 행에 나란히 있다고
> 부모·아이를 이 축으로 직접 비교할 수 없다.

> ⚠ **유아기·유소년·청소년 열의 항목 매핑은 공식 측정항목 페이지의 항목명을 코드표와
> 이름 대조해 만든 것이다.** 실측으로 확인한 것은 성인 항목뿐이다. 점수 산출의 전제이므로
> 구현 전에 대조를 다시 확인한다.

### 5.2 결정 — 준거참조 정규화

각 시험을 **그 연령대·성별의 등급 문턱**에 맞춰 정규화한다. 문턱을 공통 눈금에
고정하면 시험이 달라도 "1등급 문턱을 막 넘은 사람"은 어디서나 같은 점수가 된다.

| 앵커 | 점수 | 출처 |
|---|---|---|
| 하한 | **0** | 분포 `p2` — **미산출** (§6 ①) |
| 3등급 문턱 | **40** | 기준표 |
| 2등급 문턱 | **60** | 기준표 |
| **1등급 문턱** | **80** | 기준표 |
| 상한 | **100** | 분포 `p98` — **미산출** (§6 ①) |

**40/60/80은 기준표에서 나온 확정값이고, 0/100은 아직 아니다.** 현재 분위수 표에
`p2`·`p98` 이 없어 `min`·`p90` 을 대신 쓰고 있다. `min` 에는 측정 오류가 섞인다.

**1등급을 80에 두는 이유** — 90에 두면 성인 여 상대악력 중앙값이 91점이 되어 절반이
90점대에 몰린다. 80으로 내리면 같은 중앙값이 83점이 되고 위로 17점의 여백이 남는다.

**등급 판정과 요인 점수는 다른 것이다.** 등급은 그 연령대의 **전 기준항목 AND 조건**
으로 판정한다 — 개별 항목 문턱은 느슨하고 등급이 그것을 묶는다. 어느 항목도 3등급
문턱을 넘지 못하면 `참가` 다. 요인 점수는 항목 단위 척도이므로 등급을 대신하지 않는다.

**백분위를 척도로 쓰지 않는 이유** — 표본이 얇은 항목에서 무너진다(성인 여 41세
트레드밀 n=89). 준거참조는 문턱을 쓰므로 표본 크기와 무관하다. 백분위는 **별도
필드로 나란히** 낸다.

### 5.3 점수 함수

앵커 사이를 구간별 단조 보간한다.

```
score(v) =
  0                      v ≤ x_low
  100                    v ≥ x_high
  y1 + (y2 − y1) · w     앵커 구간 [x1, x2] 안에서

  w = (F(v) − F(x1)) / (F(x2) − F(x1))   ← 기본 (F = 경험 CDF)
  w = (v − x1) / (x2 − x1)                ← 폴백 (선형)
```

분포 보간을 기본으로 둔다. 사람이 몰린 구간에서 변별력이 생기기 때문이다 — 하위권에서
선형과 최대 15점까지 벌어진다. `n < 30` 이면 ECDF를 믿을 수 없으므로 **선형으로
떨어뜨리고 `low_sample` 을 단다.**

> **그 점수를 응답에 실을지, `score` 를 `null` 로 내릴지는 정해지지 않았다** (§6 ④).
> 확정 전 기본값은 `null` 이다 (`03` §3.5).

방향의 정본은 코드의 `lower_is_better` 다. 기준표에 방향을 적어 두 곳이 갈라지게 하지
않는다. `lower_is_better` 항목은 앵커 순서를 뒤집어 같은 공식을 쓴다 —
**점수는 언제나 클수록 좋다.**

**3등급 문턱이 없는 항목** — 운동 체력(순발력·민첩성·협응력)은 1·2등급에만 문턱이
있다. 앵커가 둘뿐이면 0~60이 통째로 한 조각이 되어 하위 해상도가 사라진다.
**40점 앵커를 그 칸의 `p25` 로 채운다.**

### 5.4 항목 → 요인

- **요인당 항목이 하나면 요인 점수 = 항목 점수다.** 예외는 둘뿐이다
- **택1 측정**(청소년·성인 심폐지구력 `020`/`035`/`037`)은 **잰 것의 점수를 그대로** 쓴다.
  평균 내지 않는다 — 택1이라 나머지가 비는 것이 정상인데 평균은 결측을 벌점으로 바꾼다.
  둘 이상 측정된 드문 경우에는 더 최근 측정을 쓴다 (최고점을 고르지 않는다)
- **신체조성(`018` BMI·`003`·`042`·`004`)은 점수화하지 않는다.** 성인 기준이 구간
  형태(BMI 18.5~25)라 단조가 아니고, 0~100 선형 척도가 성립하지 않는다. BMI는 등급
  판정에는 쓰되 요인 점수와 섞지 않는다
- **결측은 `null` 이다. 0점이 아니다.** 0으로 채우면 측정값 없는 사용자가 전부 바닥에
  깔린다. 측정값 없음은 오류가 아니라 기본 상태다
- **요인 총점을 만들지 않는다.** 연령대마다 요인 구성이 달라 총점끼리 비교되지 않는다
- 기준항목이 둘인 나머지 조합(청소년 근지구력 `009`·`010`, 성인 순발력 `022`·`041`,
  성인 민첩성 `021`·`040`)의 처리는 정해지지 않았다 (§6 ⑥)

### 5.5 연령 처리

기준은 5세 단위 계단이다. 그대로 두면 24세와 25세 사이에서 점수가 뚝 떨어진다 —
생일 하나로 점수가 내려가는 것은 설명할 수 없다. **문턱을 연령축에서 선형 보간하되,
아래 조건에서만 한다.**

| 조건 | 보간 |
|---|---|
| 같은 연령대 안의 밴드 경계 (성인 24↔25세) | ✅ |
| 연령대가 바뀌어도 **같은 시험**이 이어지는 경계 (`012`·`028`) | ✅ |
| **시험이 바뀌는 경계** (`020` 15m↔20m, `009`↔`019`) | ❌ |

시험이 다른 문턱을 잇는 것은 서로 다른 척도를 이어 붙이는 일이다. 궤적 시계열의 키는
`(연령대, 항목코드)` 가 아니라 **`(연령대, 기준항목명)`** 이다. 이름이 바뀌면 잇지
않는다.

**연령대 경계에서 점수는 튄다 — 그리고 그것은 사실이다.** 각 나이를 자기 연령대
기준으로 채점한 중앙값이다.

| 항목 | 유소년12 | → 청소년13 | 청소년18 | → 성인19 |
|---|---|---|---|---|
| `028` 상대악력 여 | 69 | **82** (+13) | 73 | **83** (+10) |
| `012` 유연성 여 | 78 | **59** (−19) | 64 | **65** (+1) |
| `020` 왕복달리기 여 | 55 | **52** (−3) | 40 | **53** (+13) |

`020` 은 시험 자체가 15m→20m로 바뀌는데도 55 → 52로 이어진다. **자기 문턱으로
정규화하면 방법 차이가 흡수된다**는 실측 근거다. 반면 유소년↔청소년 경계의 큰 이동은
정규화의 결함이 아니라 **공단이 성장에 따라 요구 수준을 다르게 잡았다**는 사실이다
(유연성 여아 1등급 문턱이 12세 11.0cm → 13세 16.6cm).

**따라서 코호트 보정을 하지 않는다.** 보정하면 "80점 = 1등급"이 깨지고 점수가 공단
기준과 어긋나 인용이 불가능해진다. 대신 **연령 구간이 바뀐 직후 부모 화면에 안내
문구를 둔다.**

> 연령 구간이 바뀌면서 평가 기준이 올라갔습니다. 점수 변화에는 이 조정이 포함되어
> 있습니다.

### 5.6 실측 예시 — 유소년 여 11세

| 요인 | 항목 | 값 | 앵커 (0/40/60/80/100) | 점수 |
|---|---|---|---|---|
| 근력 | `028` 상대악력 | 41.3% | 6.7 / 34.8 / 39.5 / 44.4 / 53.3 | **67.6** |
| 유연성 | `012` 앉아윗몸앞으로굽히기 | 4.0cm | −29.5 / 3.0 / 6.5 / 10.9 / 18.7 | **44.2** |
| 심폐지구력 | `020` 15m왕복오래달리기 | 70회 | 0 / 40 / 51 / 62 / 83 | **89.2** |
| 순발력 | `022` 제자리멀리뛰기 | 133cm | 12 / **118**(p25) / 146 / 165 / 198 | **50.5** |

굵은 `118` 은 3등급 문턱이 없어 `p25` 로 채운 앵커다. 심폐지구력 89.2와 유연성 44.2는
다른 시험의 결과지만 "1등급 문턱을 넘었는가"라는 같은 잣대 위에 있다 — 이 프로필의
대상 요인이 유연성인 근거가 여기서 나온다.

> **위 점수는 잠정값이다.** 0점·100점 앵커가 §5.2의 대체값에 기대고 있어 `p2`·`p98`
> 이 산출되면 바뀐다. 바뀌는 폭은 아직 모른다.

### 5.7 목표 구간

**"적정치"라는 말을 필드 이름·화면 문구에 쓰지 않는다.** 정상/비정상 판정으로 읽힌다.
쓰는 말은 **기준 구간**과 **목표 구간**이다.

**목표는 다음 앵커까지로 잡는다.** 20점 단위로 문턱이 놓여 있어 "다음 등급"이 곧
목표가 되고, 그 목표에는 인용할 기준값이 붙는다. 임의의 향상률로 잡으면 근거가 없다.

### 5.8 표시 규칙

| 대상 | 점수 노출 |
|---|---|
| 아이 화면 | **하지 않는다** — 점수는 순위이고 아이 화면은 활동 중심이다 |
| 부모 화면 | 한다 (요인별 점수 + 다음 문턱까지의 거리) |
| 궤적 곡선 | **미결** (§6 ③) — 이 규약은 요인 점수를 권하고, 현재 API는 raw 밴드를 낸다 |

### 5.9 알려진 결함
