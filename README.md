# 우리가족 체력키움 (family-fitness-ai) AI

국민체력100 공개데이터 기반 가족 체력 서비스의 **AI 파트**.
국민대학교 2026-2학기 학생설계형 알파프로젝트 / 한국스포츠정책과학원 공공데이터 활용 경진대회 출품작.

> 측정값을 또래 분포 위에 올려 지금 어디쯤인지 알려주고, 처방 어휘와 운동영상을 근거로
> 한 주 분량의 미션을 **제안**합니다. 저장도 실행도 하지 않습니다 — 보호자가 승인해야 미션이 됩니다.

## 구조

```
docs/                    설계 · 인터페이스 계약
src/family_fitness_ai/   api · graph · rag · stats · ingest · labeling · common
tests/
data/                    manifest.csv 와 release/ 만 커밋한다
```

**원자료는 레포에 넣지 않는다.** 목록만 `data/manifest.csv` 로 관리하고,
실물은 zip으로 팀끼리 공유한다 ([`docs/02` §3.1](docs/02-공공데이터-관리-규약.md)).

## 핵심 결정

- **AI는 서비스 테이블에 쓰지 않는다.** 계산해서 JSON을 돌려줄 뿐이고, 저장은 전부 API
  서버가 한다. 미션은 보호자가 승인해야 생긴다 — AI에 미션을 만들 경로가 없다
- **근거 없는 답은 내지 않는다.** 인용이 0이면 거부한다. 거부는 HTTP `200` 이고 오류가
  아니며, 재시도하지 않는다
- **아이 화면에는 점수·백분위·체중이 가지 않는다.** 응답이 `child_scope` 와
  `parent_scope` 로 갈려 와, 아이 화면이 노출할 값이 애초에 페이로드에 없다
- **연령 필터는 안전 문제다.** 아이 질의에 성인 처방이 섞이지 않도록 검색 질의 자체에
  얹는다. 연령 미상 영상은 아이 프로필에 내보내지 않는다
- **측정값은 선택 입력이다.** 대부분의 사용자는 나이·성별·신장·체중까지만 넣는다는
  전제로 설계했다. 측정값이 없어도 정상 응답이고, 미측정은 `null` 이지 0점이 아니다
- **점수는 준거참조 0~100이다.** 시험이 연령대마다 달라 raw 값은 이어지지 않으므로,
  등급 문턱을 공통 눈금에 고정한다 (3등급 40 · 2등급 60 · 1등급 80)
- **원자료는 커밋하지 않는다.** 재현은 커밋된 수집·산출 스크립트로 한다
